# Changelog

## 1.2.4 — 2026-10-09
- Локальный режим, экран агента: страница могла навсегда остаться на «Подключение…» — `core/`/`vendor/` noVNC оказывались ссылками на системный `/usr/share/novnc`, которого нет в Ubuntu телефона. Теперь noVNC 1.6.0 входит в `murf-local.tgz` и восстанавливается при каждом `murf-local install/update`.
- Локальный nginx сам отдаёт статику экрана (раньше — `websockify --web`, отдельный процесс на каждый из ~40 модулей); один супервизор вместо цикла на каждую службу — меньше процессов для «phantom process killer» Android 12+.
- Рабочий стол перезапускается, если VNC не отвечает (в Termux-proot сокет, созданный другим proot-процессом, не виден), и убирает зависшие блокировки xauth/X после аварийного завершения.
- Страница экрана: сторож загрузки (через 12 с — понятная ошибка вместо «Подключение…») и `window.murfState` для приложения.
- Приложение: если локальный экран не подключился за 15 с — причина (среда/файлы noVNC/Xvnc/websockify/VNC/WebSocket) и кнопки «Перезапустить экран», «Показать журнал».
- «Локальная среда» → «Диагностика»: `murf-local doctor` — проверка всех частей среды, отчёт можно отправить или скопировать. Новые команды: `murf-local doctor`, `murf-local restart-screen`, `murf-local logs screen`.
- Скрипты в Termux передаются частями (комплект больше 128 КБ — предел одного аргумента команды).

## 1.2.3 — 2026-10-09
- Экран агента открывается быстрее: все модули noVNC загружаются параллельно (`modulepreload`), WebView кэширует статику; пример nginx кэширует `/screen/core` и `/screen/vendor`. Было ~10 с через VPN, стало ~4 с в первый раз и ~1,5 с повторно.

## 1.2.2 — 2026-10-09
- Выбор языка: «Настройки → Внешний вид → Язык / Language» — «Как в системе» или любой встроенный язык; на Android 13+ через системный per-app language.
- Экраны MURF (экран агента, телефон/Termux, Google Диск, обновления, локальный режим, размер шрифта, свайпы) переведены на английский; для прочих языков — английский.
- Адрес сервера по умолчанию задаётся при сборке (`-Pmurf.defaultServerUrl`).

## 1.2.1
- Локальный режим: запасной путь без proot-distro (распаковка и запуск через чистый proot, подмена закрытых файлов /proc), повтор с `PROOT_NO_SECCOMP` для старых ядер.
- Определение версии proot-distro 5.x, полное обновление Termux перед установкой.

## 1.2.0
- **Локальный режим**: весь агент на телефоне (Ubuntu proot в Termux: Hermes Agent, WebUI, XFCE, браузер), установка с прогрессом и возобновлением, вход в провайдера из среды, проверка сети и прокси, перенос настроек с сервера, переключение профиля «Сервер / Телефон», предложение переключиться при недоступности сервера.

## 1.1.x
