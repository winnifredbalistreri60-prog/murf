# Changelog

## 1.3.0 — 2026-10-17
- **Чат больше не зависает** при большом пинге и длинном выводе агента. Найденные причины: каждый кусок потока перерисовывал весь экран чата (обновление состояния каждые 48 мс, рассуждения — на каждый токен); незакрытый блок кода во время печати целиком прогонялся через Markwon + подсветку Prism4j 10 раз в секунду, а разбор не отменялся и копился в фоне; огромные блоки кода выводились одним Text; текст ответа склеивался строками (O(n²)) и пересчитывался по словам на каждом шаге.
- Исправлено: буфер потока (StringBuilder), строка ответа обновляется отдельно от экрана не чаще 80 мс, весь экран — примерно раз в секунду; рассуждения — раз в 120 мс; разбор Markdown в фоне, по одному за раз и по готовым блокам (~2000 символов); незакрытый блок кода показывается простым кодом без подсветки.
- **Длинный код сворачивается** после 40 строк: «Показать всё (N строк)», при печати видны последние строки; подсветка синтаксиса в фоне и только для показанных строк.
- Ровно одно SSE-подключение к потоку: события от старого подключения отбрасываются.
- **Мягкое переподключение**: NetworkCallback — переподключение сразу, как появилась сеть или сменилась (Wi-Fi ↔ мобильная); без сети попытки не тратятся; после разрыва догружается только пропущенное (replay с курсора); 5 секунд без баннера «Подключение…»; список чатов обновляется после открытого чата.
- **Очередь неотправленных**: сообщение без сети остаётся в чате бледным с пометкой «отправится при подключении», удержание — «Отправить сейчас», «Изменить», «Отменить отправку»; очередь хранится в файле и переживает перезапуск, отправляется сама по порядку. Повторно отправляется только то, что точно не дошло до сервера (ошибка DNS/соединения), чтобы не было дублей.
- Сессия из Telegram (только чтение): вместо «The server refused access» — «Это сессия из Telegram, только чтение. Начните новый чат.», сессия помечается как только для чтения.

## 1.2.5 — 2026-10-09
- Экран агента в чате больше не висит поверх переписки: он открывается только кнопкой с монитором в шапке чата (зелёная точка — агент сейчас работает).
- Новая настройка «Настройки → Взаимодействие → Мини-превью экрана в чате» (по умолчанию выключена). Если включить — пока агент работает, в углу чата маленький экран: его можно перетащить или закрыть × (до конца этой задачи).

## 1.2.4 — 2026-10-09
- Локальный режим, экран агента: страница могла навсегда остаться на «Подключение…» — `core/`/`vendor/` noVNC оказывались ссылками на системный `/usr/share/novnc`, которого нет в Ubuntu телефона. Теперь noVNC 1.6.0 входит в `murf-local.tgz` и восстанавливается при каждом `murf-local install/update`.
- Локальный nginx сам отдаёт статику экрана (раньше — `websockify --web`, отдельный процесс на каждый из ~40 модулей); один супервизор вместо цикла на каждую службу — меньше процессов для «phantom process killer» Android 12+.
- Рабочий стол перезапускается, если VNC не отвечает (в Termux-proot сокет, созданный другим proot-процессом, не виден), и убирает зависшие блокировки xauth/X после аварийного завершения.
- Страница экрана: сторож загрузки (через 12 с — понятная ошибка вместо «Подключение…») и `window.murfState` для приложения.
- Приложение: если локальный экран не подключился за 15 с — причина (среда/файлы noVNC/Xvnc/websockify/VNC/WebSocket) и кнопки «Перезапустить экран», «Показать журнал».
- «Локальная среда» → «Диагностика»: `murf-local doctor` — проверка всех частей среды, отчёт можно отправить или скопировать. Новые команды: `murf-local doctor`, `murf-local restart-screen`, `murf-local logs screen`.
- Скрипты в Termux передаются частями (комплект больше 128 КБ — предел одного аргумента команды).
- Проверено на реальном телефоне: vivo X300, Android 16, arm64 — локальный режим и экран работают.

## 1.2.3 — 2026-10-09
- Экран агента открывается быстрее: все модули noVNC загружаются параллельно (`modulepreload`), WebView кэширует статику; пример nginx кэширует `/screen/core` и `/screen/vendor`. Было ~10 с через VPN, стало ~4 с в первый раз и ~1,5 с повторно.

## 1.2.2 — 2026-10-09
- Выбор языка: «Настройки → Внешний вид → Язык / Language» — «Как в системе» или любой встроенный язык; на Android 13+ через системный per-app language.
- Экраны MURF (экран агента, телефон/Termux, Google Диск, обновления, локальный режим, размер шрифта, свайпы) переведены на английский; для прочих языков — английский.
- Адрес сервера по умолчанию задаётся при сборке (`-Pmurf.defaultServerUrl`).
