# Code of Conduct / Кодекс поведения

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/).

## Our pledge / Наши обязательства

We want participation in MURF to be a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.
Мы хотим, чтобы участие в MURF было комфортным для всех, независимо от возраста, внешности, инвалидности, национальности, пола, гендерной идентичности, опыта, образования, социального положения, религии и ориентации.

## Expected behavior / Ожидаемое поведение

- Be respectful and constructive; assume good intent. / Уважительно и по делу; исходите из добрых намерений.
- Give and accept feedback gracefully. / Давайте и принимайте замечания спокойно.
- Never post other people's personal data, credentials, server addresses or tokens. / Не публикуйте чужие персональные данные, пароли, адреса серверов и токены.

## Unacceptable behavior / Недопустимо

Harassment, insults, sexualized language or imagery, trolling, personal or political attacks, doxxing, and any conduct that would be inappropriate in a professional setting.
Оскорбления, травля, сексуализированный контент, троллинг, личные и политические нападки, раскрытие чужих данных.

## Enforcement / Применение

Maintainers may edit or remove comments, issues and PRs, and temporarily or permanently ban contributors who violate this code.
Report problems privately to the maintainer via [GitHub private vulnerability reporting](https://github.com/winnifredbalistreri60-prog/murf/security/advisories/new) or by contacting the repository owner on GitHub. Reports are handled confidentially.
Сообщить о нарушении можно приватно через GitHub (ссылка выше) — обращения рассматриваются конфиденциально.
