# MURF Android

Jetpack Compose app (`com.uzairansar.hermex` namespace, inherited from Hermex). See the top-level [README](../README.md).

```bash
./gradlew assembleDebug testDebugUnitTest
./gradlew assembleDebug -Pmurf.defaultServerUrl=https://your-server.example   # optional default server
```

MURF-specific code lives in `app/src/main/java/com/uzairansar/hermex/agent/` (screen, phone bridge, Termux, Google Drive, updates, local mode, language, font size).
The local-mode script bundle `app/src/main/assets/murf-local.tgz` is generated by `../server/local-mode/build-bundle.sh`.
